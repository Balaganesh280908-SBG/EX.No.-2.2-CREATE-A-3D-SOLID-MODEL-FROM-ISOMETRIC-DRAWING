# EX.No.-2.2 CREATE A 3D SOLID MODEL FROM ISOMETRIC DRAWING


## AIM: 

To create a 3Dmodel from the given isometric drawing using fusion 360 tool. 

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE

## Step 1 
Draw a centre rectangle of width 100 mm and height 60 mm. Extrude the rectangle to a length of 30 mm. Draw a circle of diameter 50 mm at the origin and extrude it.
- Open Autodesk Fusion 360 and select the XY plane.
- Use the Rectangle tool to draw the base sketch.
- Apply the required dimensions using Sketch Dimension.
- Use the Extrude command to create the 3D base body.
- Draw the circle at the origin and apply the 50 mm diameter.

<img width="275" height="455" alt="image" src="https://github.com/user-attachments/assets/38d74513-f1f4-4e4d-9648-50f98c6c6c36" />

## Step 2 
Switch to the top view and draw a square of 10 mm on each side. Draw a circle of diameter 20 mm on the other side of the base rectangle.
- Select the top face of the base model and create a new sketch.
- Use the Rectangle tool to draw a 10 mm × 10 mm square.
- Use the Circle tool to draw a circle of 20 mm diameter.
- Position both shapes according to the given isometric drawing.
<img width="292" height="402" alt="image" src="https://github.com/user-attachments/assets/39a78612-1ec8-47f6-869a-f01180f78843" />

## Step 3 
Extrude the square and the circle. Position the square and the circle with respect to the sides of the base rectangle, with a dimension of 15 mm each, and extrude them.
- Click Finish Sketch to complete the sketch.
- Select the square and circular profiles.
- Use the Extrude command to create the required 3D features.
- Check the position and height of both features.
## Step 4 
Draw a rectangle of 30 mm × 10 mm at the top centre of the base rectangle. Use the Chamfer command to make the edge slanting.
- Select the top surface and create a new sketch.
- Draw the rectangle using the given dimensions.
- Finish the sketch and select the required edge.
- Apply the Chamfer command to create the slanting edge as shown in the drawing.

## Step 5 
Click Finish Sketch, then go to Design, choose Drawing and select From Design. Place the front view, top view, side view and isometric view on the sheet.
- Select the required drawing standard and sheet size.
- Choose the appropriate sheet orientation.
- Adjust the scale and position of each view.
- Check that all four views are clearly visible.
- Verify the dimensions with the given isometric drawing.
